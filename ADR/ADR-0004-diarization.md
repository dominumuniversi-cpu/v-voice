# ADR-0004: Диаризация — серверные окна в MVP, онлайн — фаза 2

Дата: 26.11.2026 · Статус: принято

## Контекст
Онлайн-диаризация в реальном времени бывает вендорная; own-host онлайн даёт прирост сложности и снижение качества.

## Решение
MVP: после записи — pyannote на сервере (точность); в живой ленте — вендорная диаризация, если провайдер её даёт,
иначе «Голос 1/2» по эвристике. Онлайн-кластеризация (3D-Speaker / CAM++) — фаза 2.

## Последствия
+ меньше риска в MVP, разбор спикеров точный; − «кто говорит» в живой ленте становится позже.
