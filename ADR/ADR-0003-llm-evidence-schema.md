# ADR-0003: LLM-разбор по строгой схеме с обязательной цитатой

Дата: 26.11.2026 · Статус: принято

## Контекст
LLM склонны «doписать» задачи из воздуха; в задачник нельзя пускать непроверенное.

## Решение
Схема ответа фиксирована (JSON). Каждый элемент обязан иметь `evidence{start_s,end_s,quote}`, причём
цитата проверяется по транскрипту (подстрока, ≥ 12 символов). Элементы без цитаты отбрасываются
валидатором. Одобрение — только действием пользователя.

## Последствия
+ меньше ложных задач, всё прослеживается до реплики; проще объяснить и отладить;
− некоторая часть «полезного» может отсечься — компенсируем отдельным списком «возможно, задача».
