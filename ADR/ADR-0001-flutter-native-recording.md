# ADR-0001: Запись через нативную оболочку (Flutter) с нативными мостами

Дата: 26.11.2026 · Статус: принято

## Контекст
Запись должна работать при заблокированном экране на Android и по возможности на iOS.
Веб/PWA в фоне страницу приостанавливает; нативность для записи обязательна.
Альтернативы: React Native (та же нативность мостов), Kotlin/Swift раздельно (дороже в поддержке),
Flutter (единый UI, зрелая экосистема), PWA (не годится для записи в фоне).

## Решение
Оболочка — **Flutter**; запись и уведомление — **нативные** (Android: foreground `microphone`-сервис;
iOS: AVAudioEngine + фоновый аудио-сеанс). UI и логика доставки — Dart.

## Последствия
+ один код UI/логики на две платформы, зрелые плагины разрешений и фоновой работы;
− нативный слой нужно писать и держать отдельно под каждую платформу;
− iOS-риск фоновой записи остаётся и должен быть честно описан (см. ARCHITECTURE §7).
