## Единственное, что блокирует всё остальное

**Ключ распознавания речи.** Без него работает только заглушка `fake`, а всё остальное
проверено лишь на ней. Живой прогон «сказал вслух — получил задачу» невозможен.

Нужны две строки:

```
VV_ASR_PROVIDER=<speechmatics | deepgram | assemblyai>
VV_ASR_KEY=<ключ>
```

и, если задачи должны уходить в задачник:

```
VV_LLM_PROVIDER=<deepseek | openai | gigachat>
VV_LLM_KEY=<ключ>
VV_EXPORT_HELPER_URL=https://helper.vernadsky-npc.ru
```

Вставить можно в `services/api/.env` на DIMAS — файл вне git, инструкция в
[AI-PROVIDERS.md](../ARCHITECTURE/AI-PROVIDERS.md), шаги 1–4.

**Или** — если ключа пока нет — скажите, и я подготовлю живой прогон на заглушке: он покажет,
что связка «телефон → сервер → разбор → экран» работает, но текст будет вымышленным.
