# LOCAL-RULES — VoiceTranscribator

Дата: 26.11.2026 · Локальные правила дополняют общие правила NPO (%USERPROFILE%\..\General rules).
Конфликт трактуем в пользу общего файла и сразу правим источник.

## Стек
- Мобильный клиент: **Flutter** (Dart 3.x) + нативные мосты:
  - Android: Kotlin, `ForegroundService` типа `microphone`, `AudioRecord`;
  - iOS: Swift, `AVAudioEngine` + `AVAudioSession`.
- Сервер: **Python 3.12**, FastAPI, PostgreSQL 17 (+ pgvector в фазе 2), Redis, ARQ.
- Хранилище аудио: MinIO/S3-совместимое. Дев-фолбэк — локальная ФС (только разработка).
- ML-сервис (ASR/диаризация): отдельный контейнер Python + GPU; к нему сервер ходит по HTTP.
- LLM: провайдер за портом, ключи — env сервера, никогда в клиенте.

## Порты (локальная разработка)
- 8900 — сервер API (`/api/v1`), 8910 — ML-сервис, 8920 — MinIO, 8930 — PostgreSQL (docker).
- 8901/8902… — стенды веток (по одному на ветку). Порт 8000 не занимать (проект NPC).

## Схема данных
- Все таблицы с `created_at/updated_at`; мягкое удаление не использовать для аудио (жёсткое + аудит).
- Миграции — только добавляющие в пределах спринта (правило NPC: данные не теряем).

## Тесты
- Сервер: `pytest`, basetemp — `.tmp/pytest/`.
- Клиент: `flutter test`; интеграционные (запись/фон) — на реальных устройствах, отчёт числами.

## Секреты
- `secrets/` в корне проекта, gitignore; доступ через env при запуске.
- Ключи провайдеров — в dsh-vault для агента и в `secrets/.env.dev` для локального сервера.

  внешние LLM на стендах отключены, данные — демо-сид.
