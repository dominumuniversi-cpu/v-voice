# Стенд «Умный диктофон»: /voice/

Живой сервис для проверки с телефона. Поднимается в Docker и доступен через общий nginx.

## Адреса для владельца

| Что | Адрес |
|---|---|
| Веб-экран (запись с телефона и компьютера) | **https://192.168.8.49/voice/** или **https://dimas.local/voice/** |
| Проверка сервера | https://192.168.8.49/voice/api/v1/health |

Микрофон браузеры дают только по `https` или на `localhost`: на `http://…` кнопка «Слушаю»
не работает, и страница прямо об этом говорит. Поэтому открывать стенд нужно по `https`.

Токен устройства для этого стенда: задаётся переменной `VV_DEVICE_TOKENS` при запуске контейнера.
В адресной строке токена быть не должно: страница сама убирает `?token=…` из адреса и хранит
токен в браузере. Ввести его можно в блоке «Сервер» и нажать «Перейти». Проверка систем без
токена (health, страница) работает и без него.

## Почему отдельный контейнер

Сервер не ставится на хост: у владельца уже работают другие стенды, и общий Python или
занятый порт сломали бы их. Контейнер `voice-app` живёт в сети `npc-proxy-net` и **не публикует
портов наружу** — путь один: через nginx по адресу `.49/voice/`.

## Что важно знать при правке

| Ловушка | Симптом | Правильно |
|---|---|---|
| Пустой `VV_DEVICE_TOKENS` | контейнер перезапускается по кругу | сервер честно отказывается работать открытым в сеть; токен обязателен |
| Слэш в конце `proxy_pass http://voice-app:8080/` | страница 404 | без слэша: сервер сам знает, что живёт под /voice |
| Долгая сборка | `docker build` без `--progress` печатает шаги потоком | фильтр через `findstr` держит буфер и выглядит как зависание |
| Перезапуск nginx | `nginx -t` не видит `voice-app`, пока контейнер не поднялся | сначала контейнер, потом `nginx -s reload` |

## Пересборка и перезапуск

```cmd
set DOCKER_HOST=tcp://localhost:2375
set DOCKER_CONFIG=C:\npc-docker-cfg
docker build -t v-voice-stand:latest "<репозиторий>\services\api"
docker rm -f voice-app
docker run -d --name voice-app --network npc-proxy-net --restart unless-stopped ^
  -e VV_ASR_PROVIDER=whisper -e VV_LLM_PROVIDER=fake -e VV_ASR_URL=http://voice-asr:8090 ^
  -e VV_DEVICE_TOKENS=voice2026 -e VV_HOST=0.0.0.0 -e VV_PORT=8080 ^
  -e VV_DATA_DIR=/data -v vv-data:/data v-voice-stand:latest
docker exec proxy nginx -s reload
```

## Маршрут nginx

`E:\DockerData\nginx\stands\voice.conf` — отдельный файл. Остальные роуты (sc, agentos, npc-hook)
не трогаются; после правок проверяется, что они по-прежнему отвечают 200.

## Сейчас на стенде

Модели в режиме `fake`: расшифровка подставная, разбор тоже. Смысл стенда — проверить цикл
и блокировку экрана на телефоне. Настоящий провайдер подключается заменой двух переменных
(`VV_ASR_PROVIDER=speechmatics`, `VV_ASR_KEY=...`) — см. [SETUP.md](SETUP.md).
