# Дизайн: VoiceTranscribator

Дата: 26.11.2026 · Статус: три концепта на выбор владельца · Канон: цвет/словари — в токенах
(`docs/UI/tokens.css`), тема через CSS-переменные, тёмная и светлая.

## 1. Контекст и смысл дизайна

Приложение **слушает человека**, поэтому дизайн должен быть:
- **тихим** (не отвлекать во время разговора), **честным** (я вижу, когда меня слушают),
  **спокойным** (я не «на связи» с ассистентом, а он тихо записывает).

Три опоры: **индикатор живого слышания**, **лента реплик с говорящими** и **карточка разбора** вместо
простыни текста. Никаких «мигающих умных огоньков на весь экран» — именно они отвлекают.

## 2. Три концепта (отрендерены, смотреть PNG рядом)

| Концепт | Файл | Идея | Для кого |
|---|---|---|---|
| **A. Deep Focus** | `prototypes/concept-a-deep-focus.html` (+ .png) | Тёмный кинематографичный фон, светящаяся сфера-«ухо», спокойные карточки, сине-фиолетовая палитра. Главное — пребывание в разговоре | личные встречи, «живой» вид |
| **B. Paper Desk** | `prototypes/concept-b-paper-desk.html` (+ .png) | Тёплый «бумажный» дневник: серифы, кремовый фон, карточки как страница протокола | деловые протоколы, печать/экспорт |
| **C. Signal** | `prototypes/concept-c-signal.html` (+ .png) | Инженерная тёмная тема: моноширинные цифры, уровни сигнала, цвет по спикерам | длинные записи, мониторинг, «пульт» |

Все три — на одних токенах из `tokens.css` (переменные: `--vt-bg / --vt-surface / --vt-accent / --vt-live`
и т.д.), поэтому концепты можно смешивать без перерисовки: палитра меняется в одном файле.

## 3. Структура экранов (общая для всех концептов)

1. **Слушаю** — таймер, уровень сигнала, число голосов, чипы «шум отсечён / язык / в фоне»,
   живой текст с именами, кнопки «пауза / стоп / метка».
2. **Разбор** — вкладки «Выжимка / Задачи / Транскрипт»; выжимка списком, задачи с цитатой и владельцем,
   встреча/напоминание, открытые вопросы; кнопка «В задачник».
3. **Записи** — список сессий с длительностью, спикерами, статусом разбора.
4. **Настройки** — подключение моделей (пресеты), голос владельца, лимиты, хранение.

## 4. Правила UI (наследуем UI-канон VERN-OS)

- Одна primary-кнопка на панель: на «Слушаю» это **стоп** (красный, крупный).
- Деструктив и ошибки — центрированный `dialog`, не `confirm()`; тосты справа-снизу на веб-версии.
- Статусы — только через словарь «ключ → подпись → цвет» (запись/пауза/разбор/готово/ошибка).
- Иконки — единая линейка, stroke 1.8–2, без эмодзи в названии статусов.
- Шрифт: Inter (текст) + JetBrains Mono (таймеры/цифры) — обе свободные.
- **Индикатор записи обязателен** на экране и в уведомлении — юридическое и этическое требование.

## 5. Что нужно от владельца

Выбрать концепт (или «A + элементы C»). После выбора — задача «Дизайн-система v1»: иконки, пустые
состояния, онбординг с согласием на запись, экран подключения моделей.

## Как показать концепции

Откройте `docs/UI/prototypes/index.html` — одна страница с превью всех трёх концепций и ссылками
на живые макеты. Отдельного сервера не требуется: файл открывается прямо из проводника.

Локальный показ (необязательно):

    npx http-server docs/UI/prototypes -p 8123

Затем http://127.0.0.1:8123/ — тот же индекс, но с живыми макетами в одном окне.
