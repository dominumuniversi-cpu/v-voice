### Найденный баг (и вывод)

Первый прогон CI был красным: в `run_checks.py` подстановка превратила `\n` внутри строки в настоящий
перевод строки — Python такое не собирает. Локальные проверки этого не видели, потому что Python в среде нет.
**Вывод, который теперь закреплён в отчёте:** локальная зелёная проверка ничего не говорит о python-коде,
пока его не прогонит настоящий интерпретатор; CI — единственный источник правды для серверной части.
