## Что нашлось по дороге (и было исправлено)

1. **Android: событийный канал был MethodChannel** — Dart никогда не получил бы событий; приложение «работало» бы молча.
2. **Android-проекта не было вовсе** — APK не собирался в принципе; выяснилось только после добавления шага сборки.
3. **Две ошибки в формулах**: длина WAV в миллисекундах считалась неверно; тест проверял возвращаемое значение `None` вместо состояния.
4. **Тест обрыва связи выявил реальный дефект**: закрытие потока событий оставляло «запись идёт».
5. **Java 25 на раннере ломала Gradle** — прибита Java 17; выглядело как ошибка проекта.
