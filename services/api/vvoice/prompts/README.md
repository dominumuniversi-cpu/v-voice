# Промпты разбора

Промпты лежат файлами рядом с кодом, а не в строках внутри модулей. Причина простая:
формулировка промпта — это то, что определяет, какие задачи модель найдёт. Её нужно
перечитывать, сравнивать и править отдельно от Python.

| Файл | Для чего |
|---|---|
| `digest_ru.md` | системный промпт итогового разбора на русском |

Правила версионирования:

- изменил формулировку — опиши в сообщении коммита, что именно и почему;
- если меняется правило (например, длина цитаты), сначала обнови ТЗ и валидатор, потом промпт;
- промпт не должен противоречить `evidence.py`: валидатор всё равно отбросит элемент без цитаты.
